# Roadmap

## V1
Validated Quick Look types plus a standalone inspector; structured JSON/YAML/TOML/XML/ENV, streaming JSONL/logs, CSV/TSV, safe SQLite, Markdown, metadata, settings, accessibility, lifetime Pro, App Store release and support pages. All 21 phases remain required.

## V1.1
Reliability fixes from real usage and macOS routing regressions first. Consider plist, SQL and additional code formats only after V1 gates pass.

## V1.2
Evaluate Parquet and IPYNB with dependency, memory, sandbox and demand evidence. No commitments yet.

## V2
Explicit user-triggered actions: format/minify JSON, JSON/YAML/CSV conversions, hashing, copy path, Open Terminal, batch rename, image conversion, metadata removal. Requires a new mutation-safety design; none belong in V1.

## Future Ideas
Certificates, JWT inspection, hex/binary previews, optional automation/folder monitoring and future Developer ID edition. Rule-driven move/Trash workflows need separate safety and permission requirements. No current AI or cloud requirement.
