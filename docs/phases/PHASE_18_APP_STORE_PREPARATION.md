# Phase 18 — App Store Preparation

## Goal
Prepare accurate commercial identity, StoreKit products and submission metadata.

## Dependencies
Phase 16, Phase 17. All required earlier gates must pass before production work starts.

## Technical Decisions
No final screenshots or naming work before validated product behavior.

## Tasks
- [ ] Finalize name after domain/trademark research and update centralized branding
- [ ] Confirm bundle ID, category, semantic version and unique build number
- [ ] Write subtitle, description and keywords within current Apple limits
- [ ] Complete privacy policy, support URL and accurate App Privacy answers
- [ ] Prepare final icon and screenshots from stable UI using synthetic data
- [ ] Configure and localize lifetime non-consumable StoreKit product
- [ ] Verify sandbox purchase/restore and TestFlight/internal testing where applicable
- [ ] Prepare review notes explaining extensions, offline use and sample files
- [ ] Check current submission requirements and prevent submission until QA passes

## Testing Requirements
- [ ] Audit all format claims against compatibility evidence
- [ ] Verify storefront metadata, links, screenshots and product IDs
- [ ] Run packaged sandbox purchase/restore and clean install
- [ ] Review privacy answers against dependency and network audits

## Acceptance Criteria
All required store assets and metadata exist, match tested behavior and validate; commercial identity and review build are ready.
The phase cannot be marked complete until its applicable build, tests, no-blocker, documentation and manual-acceptance gates all pass. Inapplicable gates require an explicit rationale.

## Risks
Name conflicts, outdated submission rules, inaccurate privacy claims and IAP review issues.

## Deliverables
- App Store metadata drafts
- screenshot assets
- review notes
- completed release checklist
